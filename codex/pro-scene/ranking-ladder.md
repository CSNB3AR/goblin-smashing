# Prestige & Ranking Ladder (resolved)

Named tiers: **Bronze, Silver, Gold, Platinum, Diamond, Master, Grandmaster**, then a regional **Top 500** cap above that, not everyone can reach it, the game is global with millions of players across many countries. This replaces an earlier, superseded set of numeric MMR placeholders entirely.

**Ladder rank and pro/tournament status are related but distinct tracks.** A player can be Grandmaster without being Top 500, and can still carry a pro marker on their profile from actually qualifying into real tournaments, ladder rank alone doesn't confer that marker. Contenders-tier players (the development league below the Pro League, see `codex/pro-scene/tournaments-and-events.md`), informally called **Open Contenders**, generally sit around Masters. Haruto Murayama (see `codex/characters/haruto-murayama.md`) is the clean illustration: an early Grandmaster, not Top 500, but carries a pro marker from real tournament qualification.

**Three real tiers, in order:** the basic ladder above (Bronze through Top 500), Open Contenders (competing in what's informally called the **Challenger's League**, the Contenders League's actual competitive circuit), and the Pro League itself, which runs its own regional structure under the HGO Pro League banner (see `codex/lore/hgo-timeline-and-real-world-stakes.md`). A player climbs through real competitive results, not ladder rank alone.

See `codex/arena/overview.md` for how ladder rank interacts with the arena's queue system.

## Tournament points, a separate track from ladder rank

Bracket tournaments like Winter Bash (see `codex/pro-scene/winter-bash-tournament.md`) run on their own **win-based points system**, no points for a loss, a small completion bonus just for finishing the qualifying stretch. Deliberately not solo-performance-weighted, no individual scoring like KDA feeds tournament standing, a team-sport design choice consistent with the control/King-of-the-Hill win condition (see `codex/pro-scene/tournaments-and-events.md`). This stays fully separate from the named-tier ladder above, a player's Bronze-through-Top-500 standing doesn't convert into or from tournament points.

**HGO Points, the broader circuit track.** Generalizing what Winter Bash's own points system does in isolation, **HGO Points** accumulate from placements across local tournaments, regional LAN events, and bracket tournaments alike, feeding the already-locked **World Circuit** (the season-long regional-to-national qualifying structure feeding the World Championship, see `codex/pro-scene/tournaments-and-events.md`), not a competing structure. Regional standing uses the same region names already locked for Winter Bash's qualifying (EMEA, Americas, APAC, China), not a separately-invented "circuit" name. **Winter Bash is the first event to award HGO Points under this system.**
