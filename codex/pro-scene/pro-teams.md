# Pro Guilds (background roster, for future-chapter use)

The competitive units in HGO are **guilds**, not fixed small teams (the file keeps its old name so cross-references resolve). Pro guilds run about 50 members and field up to 20 in a Siege session, with garrison troops filling any gaps (capped in the Siege Pro League). The closed beta had only about 5,000 players, so these are the guilds organized enough to matter, with the region tag marking where members are based. Twelve qualified for the Season Zero finale. Each entry is a one-line identity, background texture to draw from when a guild needs to mean something in a scene rather than just be named. See `codex/pro-scene/tournaments-and-events.md` for the formats and `codex/pro-scene/guilds.md` for the economy-side roster.
