## How D&D challenge rating maps (baseline)
Challenge rating to Class: CR 0 to 2 is Class I, 3 to 7 is Class II, 8 to 15 is Class III, 16 and up is Class IV. A D&D stat block shrinks to one HGO line: name, Class, level band, one signature art or spell with its tier, and what it drops. Monster type (beast, humanoid, undead, fiend) only sets which materials it drops.
