# Creatures — Overview

Original to HGO, described functionally only, not modeled on or naming any outside reference (same non-attribution convention already locked for the deck-building layer, see `codex/lore/deck-building-rarity-and-classes.md`). PvE encounter content, the monsters and mythical beasts a player actually fights outside player-vs-player content.

## Class I-IV threat tiers

A four-band difficulty system, Class I weakest through Class IV strongest, leaves room to extend upward later if the story needs a fifth band. Not the same scale as the rarity ladder (`codex/lore/deck-building-rarity-and-classes.md`, Common through World) or the magic/Physical Arts tier systems, this is specifically about how dangerous a creature is to fight, independent of what drops off it.

- **Class I** — common, low-threat, the kind of thing a fresh character encounters constantly and mostly solo-clears without much risk. See `codex/creatures/class-1.md`.
- **Class II** — a real fight, usually still soloable by a capable player but not a given, groups of these are genuinely dangerous to an unprepared solo player. See `codex/creatures/class-2.md`.
- **Class III** — dangerous, typically requires a party or a genuinely skilled/overleveled solo player, the kind of thing that shows up as a named regional threat rather than ambient wildlife. See `codex/creatures/class-3.md`.
- **Class IV** — world-boss/raid tier, server-event scale, tied to World Boss Raids and Server Firsts (see `codex/pro-scene/tournaments-and-events.md`). Rare, named, remembered. See `codex/creatures/class-4.md`.

## Stat-block convention

Each entry uses the existing "Creature/Hero card" format (`codex/lore/deck-building-rarity-and-classes.md`): name, a short identity line, the six Discipline+Energy stats (`codex/lore/five-disciplines-stat-system.md`) as a rough illustrative band rather than a hard number (these scale with the zone/level a creature is actually encountered in), innate/activated/triggered abilities, and a rarity from the standard ladder. Narrative shorthand, not literally shown to the reader as a UI card for every encounter, per the existing house convention.

## Scope note

Each class file below carries a representative, expandable roster, not an exhaustive monster manual. More entries get added as later chapters need them.
