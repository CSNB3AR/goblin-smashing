# Magic Affinities — Relocated

Moved to `codex/magic/`. What used to be called "affinities" are now named schools, same underlying mechanical system. See `codex/magic/overview.md` for how a caster ends up in a school, and one file per school (`codex/magic/pyromancy.md`, `codex/magic/cryomancy.md`, `codex/magic/stormcraft.md`, `codex/magic/geomancy.md`, `codex/magic/radiance.md`, `codex/magic/umbral-arts.md`, `codex/magic/arcanism.md`) for the individual feel/flavor and skill tree. Tatsuya's own affinity, Dark, is now Umbral Arts, see `codex/magic/umbral-arts.md`.
