# Magic Affinities — Relocated

Moved to `codex/magic/`. What used to be called "affinities" are now named schools, same underlying mechanical system. See `codex/magic/overview.md` for how a caster ends up in a school, and one file per school (`codex/magic/book-of-embers.md`, `codex/magic/book-of-frost.md`, `codex/magic/book-of-tempest.md`, `codex/magic/book-of-stone.md`, `codex/magic/book-of-radiance.md`, `codex/magic/book-of-the-veil.md`, `codex/magic/book-of-the-arcane.md`) for the individual feel/flavor and skill tree. Tatsuya's own affinity, Dark, is now Book of the Veil, see `codex/magic/book-of-the-veil.md`.
