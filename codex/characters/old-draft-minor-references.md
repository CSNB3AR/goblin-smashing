# Old-Draft Minor Character References

Small, one-off, or not-yet-reconfirmed named characters pulled forward from `bible/old-draft-chapter-bible.md` as raw material. None of these are locked into current canon yet, they're here so the names and rough sketches aren't lost, and so nothing gets silently reinvented under a different name later.

## Ms. Sugiyama

Hospital nurse, warm recurring presence in the old draft, teases Rin (now Tatsuya) and Yuna. Good candidate for texture once the hospital/Yuna material gets resequenced later in the timeline (see `codex/characters/yuna-yunaile.md`).

## Dr. Inoue

Treating physician for Ohema in the old draft, delivers the surgery deadline stakes directly. Current canon keeps Ohema's surgery urgency (see `codex/characters/ohema-kazehaya.md`) but hasn't yet re-confirmed whether a named physician character is still wanted on the page.

## Shinji Takamura

Old-draft name for a Tabuchi family butler/retainer, source of threatening messages to Tatsuya. **Superseded** by Jarvis ("Jarvy," see `codex/characters/jarvis.md`) as the confirmed current butler character. If a separate, more overtly threatening retainer figure is still wanted distinct from Jarvis, that would need to be reintroduced as a new character, not assumed to be the same as Jarvis.

## Rian, Spellweaver_Lyn, Talo, Joss (New Covenant guild party)

Level 6 enemy player party from the old draft's Chapter 11/11.5 combat setpiece, cashed-in Legacy Point gear, answers to PK_Wraith. Good template for how enemy players talk and coordinate under pressure, not yet reconfirmed as characters who'll actually appear in the redraft.

## PK_Wraith

Named PvP faction leader the New Covenant party answers to in the old draft. Possible recurring rival, not yet reconfirmed for the redraft.
