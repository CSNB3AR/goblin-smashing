# Archive — Superseded Planning Material

Everything in this folder is old planning material from earlier drafting passes. It's kept for historical reference only, none of it should be treated as current.

- `chapter-01.md` through `chapter-06-plus.md` — early, pre-draft beat plans for the opening chapters, written before those chapters were actually finalized on the page. Superseded by `outline/chapters-1-7-summary.md`, which is generated directly from the final committed prose in `chapters/`, not from planning notes.
- `restructuring-notes.md` — the rationale for an early restructuring pass off the old draft. Historical context only, the decisions it describes are long since settled and reflected in the actual chapters.
- `chapter-outline-1-11.md` — the original chapter-by-chapter beat plan for Chapters 1 through 11, written before Chapters 1-9 were actually drafted and before the story's direction past Chapter 9 was locked into the Winter Bash / Haya Storm Rise arcs. Superseded by `outline/chapters-1-7-summary.md` + `outline/chapter-08.md` + `outline/chapter-09.md` for what's drafted, and by `outline/act-one-winter-bash.md` + `outline/act-two-haya-storm-rise.md` for what's next.

If you need to know what's actually current, start at `outline/chapter-outline.md` in the parent folder, not here.
